# Artify — апликација за водење на бизнисот

Сопствена, бесплатна замена за base44 апликацијата: нарачки, клиенти, продукти и трошоци, залиха, статистика, рекламни трошоци, freelance проекти и календар. Светла/темна тема, сопствено лого, работи на телефон.

**Live:** https://artify-app.github.io/

## Како функционира

- Статична апликација (Vite + React + TypeScript + Tailwind), хостирана бесплатно на **GitHub Pages**. Секој `git push` на `main` автоматски ја објавува (`.github/workflows/deploy.yml`).
- Податоците **не се во кодот**. Два режима:
  - **Локално** (стандардно) — сè се чува во прелистувачот (IndexedDB) на тој уред. Backup/увоз во еден JSON фајл од Подесувања.
  - **Облак (Supabase, бесплатен план)** — најава со е-маил/лозинка, податоците се во твоја Postgres база, достапни од секој уред. Row Level Security: само ти ги гледаш твоите редови.

## Прв пат

1. Отвори ја апликацијата → **Увези backup** → избери го `artify-backup-….json` (податоците пренесени од base44).
2. Подесувања → прикачи лого, избери боја и тема.

## Поврзување со Supabase (кога ќе имаш 10 минути)

1. supabase.com → New project (регион Frankfurt). Запиши ја лозинката за базата.
2. **SQL Editor** → залепи го `supabase/schema.sql` → Run.
3. **Authentication → Users → Add user** → твој е-маил + лозинка (со ова се најавуваш во апликацијата).
4. **Project Settings → API** → копирај **Project URL** и **anon public key**.
5. Во апликацијата: Подесувања → „Каде се чуваат податоците“ → залепи ги двете → **Поврзи Supabase** → најави се → **Пренеси ги локалните податоци во облак**.
6. Project URL и publishable клучот се во `.env.production` (јавни се по дизајн). Со нив апликацијата е поврзана на секој уред, а `keepalive.yml` секој ден ја „буди“ базата за Supabase да не ја паузира.

Ако проектот сепак се паузира (7 дена без активност): Supabase панел → **Restore project** → освежи ја страницата.

## Локален развој

```bash
npm install
npm run dev      # http://localhost:5173/
npm run build    # dist/
```

## Структура

- `src/pages/` — страници (Преглед, Нарачки, Нова нарачка, Клиенти, Продукти, Залиха, Статистика, Трошоци, Freelance, Календар, Подесувања)
- `src/lib/store.ts` — централна состојба (zustand) + избор на адаптер за чување
- `src/lib/storage/` — `local.ts` (IndexedDB) и `supabase.ts`
- `src/lib/calc.ts` — клиенти, статистика, увиди, пресметки
- `supabase/schema.sql` — шема и безбедносни правила
